# 💖 روز من — Roz-e Man

> برنامه‌ریزی هوشمند، زندگی منظم

**«روز من»** یک اپلیکیشن همه‌کاره برنامه‌ریزی روزانه برای دانش‌آموزان، دانشجویان و همه افرادی است که می‌خواهند زندگی منظم‌تری داشته باشند.

---

## ✨ امکانات

- 📅 **برنامه هفتگی درسی** — برنامه کلاسی خود را برای هر روز هفته وارد کنید
- ✅ **مدیریت تکالیف** — همه تکالیف با جزئیات، تاریخ و ساعت
- 📝 **برنامه امتحانات** — هیچ امتحانی را فراموش نکنید
- 🔔 **یادآورهای هوشمند** — در زمان مناسب یادآوری می‌شود
- 💖 **دفترچه خاطرات روزانه** — لحظات خوب را ثبت کنید
- 📊 **آمار و پیشرفت** — میزان پیشرفت خود را ببینید
- ⚙️ **حالت تاریک و قفل برنامه** — امنیت و راحتی

---

## 🎨 طراحی

- رابط کاربری کاملاً راست‌چین (RTL)
- رنگ‌بندی مدرن و آرامش‌بخش
- فونت خوانا و مناسب زبان فارسی
- طراحی ساده و بدون پیچیدگی
